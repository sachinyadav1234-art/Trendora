# Trendora — Shopify E-commerce Theme

Trendora is a modern, high-converting, and responsive fashion e-commerce storefront built as a custom Shopify theme.

## Tech Stack

- Shopify Liquid
- HTML5 & CSS3 (Custom Variables & Dark Mode)
- Vanilla JavaScript (Ajax Cart, LocalStorage Engines)
- Shopify CLI
- Git & GitHub

## Core Features & Suite

- **Slide-out Ajax Drawer Cart**: Instantly open drawer cart with dynamic live subtotal update, item quantity controls, and cart order notes.
- **Free Shipping Progress Bar**: Dynamic distance indicator to free shipping threshold ($100).
- **Predictive Live Search**: Search-as-you-type live suggestions with product thumbnails and pricing.
- **Wishlist Engine**: LocalStorage-based product favoriting system with heart icon buttons and header counter.
- **Sticky Add-to-Cart Bar**: Floating bottom buy bar on product detail pages when scrolling.
- **Size Guide Modal**: Apparel measurement guide modal popup with standard sizing tables.
- **Stock Scarcity & Urgency Badges**: Low stock inventory warning indicators (*"Only X left in stock"*).
- **Estimated Delivery Calculator**: Dynamic estimated delivery date calculation widget.
- **Flash Sale Countdown Banner**: Animated countdown clock for limited-time promotions.
- **Recently Viewed Products Section**: LocalStorage-backed recently browsed product tracker.
- **Instagram / UGC Photo Grid**: Responsive user-generated photo gallery grid.
- **Dark Mode Theme Switcher**: Instant light/dark theme toggle with CSS variable customization.
- **SEO JSON-LD Microdata**: Structured data schemas for Product, Organization, Offer, and Breadcrumbs.
- **Back-to-Top Button**: Smooth floating scroll to top button.

## Project Structure

- `sections/` — Custom Shopify Liquid sections
- `snippets/` — Reusable Liquid components & modals
- `templates/` — Shopify page templates & JSON layouts
- `assets/` — CSS stylesheets & JS engines (`trendora-core.js`, `wishlist.js`)
- `layout/` — Main theme layout wrapper (`theme.liquid`)
- `config/` — Theme settings and schema

## Development

Developed locally using Shopify CLI and fully compatible with Shopify Online Store 2.0.
