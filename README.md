# Trendora — Shopify E-commerce Theme

Trendora is a modern and responsive fashion e-commerce storefront built as a custom Shopify theme.

## Tech Stack

- Shopify Liquid
- HTML5
- CSS3
- JavaScript
- Shopify CLI
- Git & GitHub

## Features

- Responsive homepage
- Custom hero section
- Featured products
- Shop by category
- Product detail page
- Product variants
- Quantity controls
- Add to Cart
- Cart management
- Collection page
- Product sorting
- Product search
- Newsletter signup
- Responsive mobile design
- Custom header and footer

## Project Structure

- `sections/` — Custom Shopify sections
- `templates/` — Shopify page templates
- `assets/` — CSS and theme assets
- `layout/` — Theme layout
- `config/` — Theme configuration

## Development

The theme was developed locally using Shopify CLI and tested on a Shopify development store.
